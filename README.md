# Portfolio

A modern, interactive portfolio website built with React, TypeScript, Vite, and Tailwind CSS featuring data science and AI expertise.

## 🚀 Live Demo

[View Portfolio](https://omnianasser212005-ship-it.github.io/portfolio)

## 📁 Project Structure

```
portfolio/
├── public/                  # Static assets
│   └── assets/             # Images and media files
├── src/
│   ├── components/         # Reusable React components
│   ├── pages/             # Page components
│   ├── styles/            # Global and component styles
│   │   └── index.css      # Main stylesheet
│   ├── types/             # TypeScript type definitions
│   ├── utils/             # Utility functions
│   ├── App.tsx            # Main app component
│   └── main.tsx           # Entry point
├── docs/                  # Documentation
├── .figma/                # Figma Make configuration
├── index.html             # HTML template
├── vite.config.ts         # Vite configuration
├── tsconfig.json          # TypeScript config
├── package.json           # Dependencies
└── README.md             # This file
```

## ⚡ Getting Started

### Prerequisites
- Node.js 18+ 
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/omnianasser212005-ship-it/portfolio.git
cd portfolio

# Install dependencies
npm install
# or
pnpm install
```

### Development

```bash
# Start development server
npm run dev

# Server runs at http://localhost:8443
```

### Build for Production

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```

## 📦 Deployment

### GitHub Pages

The site is configured to deploy automatically to GitHub Pages:

```bash
# Build and deploy
npm run build
# Push to main branch
git push origin main
```

Your site will be live at: `https://omnianasser212005-ship-it.github.io/portfolio`

## 🎨 Customization

### Update Profile Image
1. Replace `public/assets/profile.jpg` with your image
2. Update imports in `src/App.tsx` if needed

### Modify Content
Edit the following in `src/App.tsx`:
- `educationItems` - Education history
- `skillCategories` - Skills and competencies
- `workItems` - Work experience
- `projects` - Project portfolio
- Contact information and social links

### Styling
- Global styles: `src/styles/index.css`
- Tailwind config: `tailwind.config.js` (if exists)
- Component styles: Inline with Tailwind classes
